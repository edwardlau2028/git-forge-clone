A standalone GitHub-compatible git forge in one Node 22 process, standard library only, no git binary, no UI, no outside service. It serves Git smart HTTP (upload-pack v2, receive-pack v0), REST v3, GraphQL v4 and MCP from a single in-memory store. Kit suite: 120/120 checks, score 912 against the house reference's 900.

## Run it

```sh
node --experimental-strip-types main.ts
```
